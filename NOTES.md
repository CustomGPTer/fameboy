Fame Boy 1.0.2 adds Check for updates and More apps, a new bottom bar, and a set of fixes.

- **Check for updates** and **More apps** in Settings, plus a link to the website. Fame Boy only asks GitHub for a newer version when you tap Check now.
- A new bottom bar with an icon over each label and a highlight behind the page you are on.
- Portrait play now uses your Portrait layout from Controller Studio, and in landscape the default controls sit clear of the game picture.
- Turning the phone during an import or backup no longer stops it or closes the app.
- Another app playing sound no longer leaves a game paused for good.
- Fixes to counts, the Game unavailable message, offline matching and file permissions for linked games.

No games are included. Install over 1.0.1 or 1.0.0: your games, saves and settings are kept.
