# Fame Boy

Fame Boy is a free Android player for the Game Boy, Game Boy Color and Game Boy Advance game files you own: a sharp picture at the right shape, nine save slots and automatic saves, rewind, cheats, gamepads, a Controller Studio and encrypted backups. No games included, no adverts, no account and no tracking.

Website: https://customgpter.github.io/fameboy/

Download: https://github.com/CustomGPTer/fameboy/releases/latest/download/FameBoy.apk

## Engine source

The source of the native engine library inside the app (the bridge, build files and the LGPL blip_buf library) is in [engine/](engine/), so it can be rebuilt and relinked. The rest of the app's source is not published.
