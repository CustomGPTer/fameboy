Release notes

What changed in each version of Fame Boy. The newest is at the top.

Version 1.0.2 26 November 2026Latest

  • Check for updates and More apps in Settings, plus a link to this website. Fame Boy only goes online for an update check when you tap Check now.
  • A new bar at the bottom with an icon over each label, and a highlight behind the page you are on.
  • Portrait play now uses your Portrait layout from Controller Studio. Before, most phones used the Landscape layout in portrait too.
  • In landscape, the default controls sit clear of the game picture.
  • Turning the phone during an import or backup no longer stops it, or could close the app.
  • A game is no longer paused for good when another app plays sound: short sounds just lower the volume, and longer ones pause the game with the menu open.
  • Games added as private copies no longer use up Android's limited list of lasting file permissions, which linked games need.
  • The Game unavailable message now stays until you tap Return to library.
  • Favourites shows how many favourites you have, and counts read "1 game" rather than "1 games".
  • Offline game matching skips a linked game whose file is missing instead of stopping, and saves once at the end.
  • Taps made while an import is running now tell you to wait instead of being lost.
  • The game tiles' small label no longer runs off the edge.

Version 1.0.1 25 November 2026

  • The opening title, Privacy by design and the line of file types on the empty library are centred properly.

Version 1.0.0 25 November 2026

  • First release. Plays your own Game Boy, Game Boy Color and Game Boy Advance games with mGBA.
  • Sharp, Smooth and Original picture, palettes, nine save slots, three automatic saves and the game's own save every ten seconds.
  • Controller Studio, presets, per-game controls, gamepad and keyboard mapping, and hold-for-2× fast-forward.
  • Library with search, filters, favourites, genres from an offline catalogue, collections, tiles and list.
  • Rewind, cheats, IPS, UPS and BPS patches, folder scanning, ZIP and 7z archives, linked files and optional cover downloads.
  • Backups sealed with a password, app lock with PIN and fingerprint, and dark, light or system appearance.

Checking your download

The file for version 1.0.2 is called FameBoy.apk. It is 1.9 MB (1,940,266 bytes). Its SHA-256 checksum is:

353ed72d44aae2e7423e4d4a9818a45c8ff58e9fbdf62024973b20c9dfcfed75

On Windows, run certutil -hashfile FameBoy.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
